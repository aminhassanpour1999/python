# Python Learning Path

A structured, practice-driven curriculum for developing independent Python programming ability. The course is not tied to one textbook: Python's official documentation is the primary technical reference, supported by carefully developed lessons, deliberate practice, debugging, and cumulative projects.

**The [curriculum roadmap](./ROADMAP.md) is the source of truth for topic coverage, prerequisites, planned depth, deferred topics, and learning status.** A topic appearing in a lesson or roadmap is not automatically learned or mastered.

## How to use this repository

1. Follow the order in the curriculum and respect prerequisites.
2. Study one lesson at a time; do not treat the repository as a book to skim.
3. Predict example output before running code.
4. Type and modify examples yourself.
5. Attempt exercises before opening their separate solution files.
6. Debug deliberately and explain why a fix works.
7. Complete labs and cumulative projects rather than collecting notes.
8. Keep notes, code comments, and project documentation in English; use Persian explanations in study conversations when useful.
9. Mark learner progress only after actual study, independent practice, and review.

## Learning standard

The [Learning Charter](./LEARNING-CHARTER.md) defines the teaching method and quality rules. Lessons use the relevant parts of this cycle:

**Orient → Understand → Inspect → Experiment → Practice → Debug → Connect → Build → Review → Document**

Lesson-material status and learner mastery are separate. A complete draft is not automatically an approved lesson, and an approved lesson is not proof that the learner has mastered it.

- [Python Tutorial](https://docs.python.org/3/tutorial/)
- [Python Language Reference](https://docs.python.org/3/reference/)
- [Python Standard Library](https://docs.python.org/3/library/)
- [Python Packaging User Guide](https://packaging.python.org/)
- [PEP 8 — Style Guide for Python Code](https://peps.python.org/pep-0008/)

The official tutorial is a key reference, not the only teaching resource. Lessons add explanations, examples, practice, and projects where learners need more support.

## Scope

This repository teaches **Python itself**: the language, standard library, software-development practices, and programming skills required to build reliable programs. Mathematics, scientific computing, signals and systems, communications, machine learning, and research content belong in separate focused repositories. Python skills learned here will support those subjects later.

Follow the [Learning Charter](./LEARNING-CHARTER.md) and [Roadmap](./ROADMAP.md) when deciding what belongs here.
