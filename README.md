# Python Learning Path

A structured, practice-driven curriculum for developing independent Python programming ability. The course is not tied to one textbook: Python's official documentation is the primary technical reference, supported by carefully developed lessons, deliberate practice, debugging, and cumulative projects.

**The [curriculum roadmap](./ROADMAP.md) is the source of truth for topic coverage, prerequisites, planned depth, deferred topics, and learning status.** A topic appearing in a lesson or roadmap is not automatically learned or mastered.

## How to use this repository

1. Follow the order in the curriculum and respect prerequisites.
2. Read one lesson at a time; do not treat the repository as a book to skim.
3. Predict example output before running code.
4. Type and modify examples yourself.
5. Attempt exercises before viewing answer keys.
6. Debug deliberately and explain why a fix works.
7. Build the labs and cumulative projects rather than collecting notes.
8. Keep notes, code comments, and project documentation in English; use Persian explanations in study conversations when useful.
9. Mark learner progress only after actual study, independent practice, and review.

## Learning standard

The [Learning Charter](./LEARNING-CHARTER.md) defines the teaching method and quality rules. Each substantive lesson should use the relevant parts of this learning cycle:

**Orient → Understand → Inspect → Experiment → Practice → Debug → Connect → Build → Review → Document**

A lesson file being complete means teaching material is available. It does not mean the learner has mastered it. The learner's status is tracked separately in the roadmap and relevant module README.

The official tutorial is a key reference, not the only teaching resource. Lessons add explanations, examples, practice, and projects where a beginner needs more support.

## Scope

This repository teaches **Python itself**: the language, standard library, software-development practices, and programming skills required to build reliable programs. Specialized mathematics, scientific computing, signals and systems, communications, machine learning, and research content belong in their own focused repositories. Python skills learned here will support those subjects later.

Follow the [Learning Charter](./LEARNING-CHARTER.md) and [Roadmap](./ROADMAP.md) when deciding what belongs here.
