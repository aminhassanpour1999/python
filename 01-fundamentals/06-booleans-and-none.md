# Booleans and None

> **Status:** Syllabus outline. We will expand this lesson into teaching notes, a coding lab, exercises, and a small project when we study it.

## Learning objectives

- Recognize `True`, `False`, and `None` and distinguish their meanings.
- Use comparison operators to produce boolean results.
- Explain truthiness and identify common falsy values.
- Combine boolean conditions using `and`, `or`, and `not`.
- Distinguish equality from identity, especially when checking for `None`.

## Sections

1. **Boolean values** — `bool`, `True`, and `False`.
2. **Comparisons produce booleans** — connect numeric and string comparisons to their results.
3. **Boolean operators** — `and`, `or`, and `not`, including short-circuiting at a conceptual level.
4. **Truthiness** — common truthy and falsy values; do not confuse truthiness with equality.
5. **The meaning of `None`** — representing the absence of a value or a missing result.
6. **Equality and identity** — `==` compares values; `is` checks object identity. Use `is None` for a None check.
7. **Common logic mistakes** — comparing booleans unnecessarily and assuming empty values are the same as `None`.

## Coding lab

Given a measurement, calculate boolean checks such as whether it is positive or within a stated range. Add a `None` example to represent an unavailable measurement and explain why it differs from zero.

## Exercises

- Predict the result of comparison and boolean expressions.
- Classify values as truthy or falsy.
- Repair incorrect `None` checks.
- Explain the difference between `0`, `""`, `False`, and `None`.

## Knowledge check

Explain truthiness, the purpose of `None`, and when to use `is None`.
