# Testing and Software Quality

> Status: Planned syllabus only. This stage will be developed after the core Python modules. It teaches systematic verification and maintainability; it does not imply that earlier lessons or projects have already been tested.

## Lesson map

1. Testing principles and test design
2. The `unittest` framework
3. `pytest` fundamentals and test discovery
4. Fixtures, parametrization, and temporary resources
5. Testing exceptions, files, and command-line programs
6. Mocking, patching, and test isolation
7. Debugging, logging, and diagnostics
8. Formatting, linting, static analysis, and type checking
9. Continuous integration concepts and maintainable test workflows
10. Final assessment and tested project

## Learning goal

Design useful tests for normal, boundary, and failure behavior; diagnose failures; and understand what a test suite can and cannot establish.
