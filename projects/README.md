5. Personal expense tracker using structured data
6. File-based notes or task manager
7. CSV data summary and visualization

9. API or data acquisition project when prerequisites are ready
10. Scientific mini-project using numerical methods and plots

## Project workflow

- Define the problem and acceptance criteria before coding.
- Sketch inputs, transformations, outputs, and edge cases.
- Build a small working version first.
- Test normal, boundary, and invalid cases.
- Refactor for readability after it works.
- Write a concise English README and explain the design choices.
