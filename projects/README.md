# Python Projects

Projects are introduced when their prerequisites are ready. A project brief defines the problem and acceptance criteria; the learner writes and tests the implementation independently.

## Current stage

1. [Fundamentals Measurement Report](./fundamentals-measurement-report/README.md) — a straight-line command-line program combining text input, conversion, numeric calculations, Boolean reasoning, formatting, code style, and debugging.

## Planned project progression

11. Scientific mini-project using numerical methods and plots

## Project workflow

- Define the problem and acceptance criteria before coding.
- Sketch inputs, transformations, outputs, and edge cases.
- Build a small working version first.
- Test normal, boundary, and invalid cases.
- Refactor for readability after it works.
- Write a concise English README and explain design choices.
